Sécurité / Réinitialisation

ZONE ADMINISTRATEUR — ERP DEV UNIQUEMENT
Ces fonctions suppriment des données du projet RML ERP DEV. Elles ne touchent pas aux applications RML actuellement en production. Les comptes de connexion et les droits utilisateurs sont conservés, même lors d’une réinitialisation complète.
Chargement des compteurs…

Données des modules

Supprime toutes les données enregistrées dans les modules ERP (préparations chantier et futurs modules), sans supprimer les clients ni les chantiers.

Imports Excel clients

Supprime tous les clients issus d'imports Excel ainsi que leurs chantiers et données de modules associés. Les clients créés manuellement sont conservés.

Clients & chantiers

Supprime tous les clients, tous les chantiers et toutes les données des modules. Les utilisateurs et leurs droits restent en place.

Réinitialisation complète ERP DEV

Remet à zéro toutes les données métier de l'ERP DEV : modules, chantiers et clients. Les comptes Supabase Authentication et les droits d'accès sont volontairement conservés.
