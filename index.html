Référentiel central connecté

Cette V0.6.7 utilise le projet Supabase RML ERP DEV. Les clients et chantiers restent synchronisés entre les appareils connectés. Le premier module métier, Préparation chantier, est maintenant intégré directement au chantier et enregistré dans la base ERP DEV.

Cette application reste un environnement de développement séparé. Elle ne lit ni ne modifie les données de tes applications RML actuellement en production.

Derniers chantiers

Import Excel accepté : la première ligne doit contenir les en-têtes. Colonnes reconnues automatiquement : Nom / Client, Responsable, Catégorie, Téléphone, E-mail, Adresse et Notes. Le code client est attribué automatiquement par l’ERP.
